To publish with GitHub Pages:
1. Create a new GitHub repository (for example: gowthami-portfolio).
2. Upload index.html and profile.jpg.
3. Open Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and the / (root) folder, then Save.
6. GitHub will provide your public portfolio URL.

Before publishing, replace the CSP placeholder description with the real project details.
